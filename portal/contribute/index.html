Contribute to the repo

The studio keeps its source on GitHub. Fork a repository, make a focused change and send a pull request — small fixes and documentation are welcome.

How to join

  1. Fork the repository you want to work on.
  2. Create a short branch for one change.
  3. Keep the change small and describe why it is needed.
  4. Open a pull request; questions go to the Telegram contact.

Ground rules

No credentials, tokens or personal data in commits. Respect the existing style so changes can be reviewed quickly.
