# Гипотезы по диагностике конвейера WINTASK (Dolphin / Chrome / лента)

Задача зависла — не гадать, а проверить гипотезы по списку. Скрипт `diag_collect.py`
собирает факты по всем пунктам раздела «СБОР ФАКТОВ».

| # | Гипотеза | Как проверить | Признак |
|---|----------|---------------|---------|
| Г1 | **Память кончилась**: 9 профилей Dolphin (каждый — Chromium) + много вкладок → OOM, система убивает процессы | свободная RAM, суммарный RSS chrome, top-10 по памяти, pagefile/swap | used > 90%, RSS chrome десятки ГБ, в логах «Out of memory»/«не удалось выделить память» |
| Г2 | **Chrome обновился, драйвер playwright несовместим** (1.63 vs Chrome 156): `connectOverCDP` зависает | `Browser.getVersion` через сырой WebSocket (работает?) + версия playwright в проекте | CDP отвечает нативно, но playwright не коннектится; таймаут 30 с |
| Г3 | **Chrome упал/перезапустился**: CDP-порт 9222 молчит, вкладок много | доступность :9222, /json/version, /json/list, число вкладок и домены | :9222 не отвечает или вкладок 0 |

## Как действовать

1. **Причина очевидна из отчёта агента** → сразу декомпозиция задачи на конкретные шаги
   (`api/task_decompose.php`), первый кусок уходит агенту сам.
2. **Причина не очевидна** → ставится **задача по сбору ситуации**: агент запускает
   `diag_collect.py` и присылает вывод целиком. Ничего не чинить, только факты.
3. **Собранные факты + список гипотез** → выбираем гипотезу, подтверждаем, делим задачу
   на шаги, отдаём агенту первый шаг, возвращаемся в цикл.

## Сбор фактов (скрипт)

```
curl -s "http://5.144.179.170:8080/api/diag_script.php?token=<ТОКЕН>" -o diag_collect.py
```
