# Постановка задачи агенту — внутренний API трекера

> Документация лежит здесь: `http://5.144.179.170:8080/api/task_queue_doc.php`
> (тот же текст — `http://5.144.179.170:8080/docs/task-queue.md`).
> Оба адреса отдают этот файл; `/api/...` отдаётся без basic-аутентификации,
> только по ключу вызова.

**Ты можешь сам поставить задачу на фикс — без согласования с оператором.**
Трекер создаёт задачу в плане (в дереве), и как только агент освободится, её
ему отдаст сторож. Оператор увидит её в дереве и в ленте.

Текст задачи уходит агенту **ровно в том виде, в котором ты его написал**:
без ID, протокола и служебных строк. Поэтому пиши сразу то, что нужно сделать.

---

## Когда ставить задачу самому

- нашёл у себя ошибку или сбой и можешь починить — ставь задачу на фикс;
- в ленте/логе трекера или в отчёте видно, что конвейер встал;
- нужно продолжить работу, которую не смог довести в этом ходе;
- периодический чекап не требует согласования.

**Не ставить:** задачи на доработку фич без сбоя, задачи «на будущее»,
задачи, которые уже есть в плане (см. `dup` ниже).

---

## Запрос

```
POST http://5.144.179.170:8080/api/task_queue.php
Content-Type: application/json
```

**Ключ вызова не нужен, если запрос идёт с сервера агента** — трекер узнаёт
серверы агентов по IP в карточках проектов и принимает такой запрос без ключа.
Ничего настраивать не надо: просто отправь запрос.

Если ты работаешь не с сервера агента (например, с рабочего места), добавь ключ
вызова — он тот же, что для отчёта по токенам (`/api/ingest.php`):

```
X-Ingest-Key: <ключ вызова>
```

Ключ принимается в трёх видах: заголовок `X-Ingest-Key` (с пробелами — обрежутся),
`Authorization: Bearer <ключ>` или поле `ingest_key` в теле запроса.

Тело (JSON):

```json
{
  "project_ref": "WINTASK",
  "title": "Почини конвейер заявок: с 12:10 падает cron выгрузки",
  "prio": 2,
  "parent_id": 28,
  "source": "agent-selfcheck",
  "note": "ошибка в логе: timeout 30s",
  "dry_run": false
}
```

| Поле | Обяз. | Что это |
|---|---|---|
| `project_ref` | да* | направление по названию из трекера: `WINTASK`, `ADULT`, `FABRA`, `CPA`, `Game` |
| `chat_id` | да* | вместо `project_ref` — ID чата направления |
| `title` | да | текст задачи, одна строка, до 250 знаков, с глагола: что сделать |
| `prio` | нет | `1` — деньги (по умолчанию `2`), `3` — обслуживание |
| `parent_id` | нет | ID узла, внутри которого создать задачу (например подпроекта) |
| `source` | нет | откуда задача (`watcher`, `agent-selfcheck`, …) — для группировки и лимита |
| `note` | нет | подробности; агенту не показываются, видны в трекере |
| `dry_run` | нет | `true` — только проверить, ничего не создавая |

\* нужен либо `project_ref`, либо `chat_id`.

### Ответ

```json
{"ok":true,"task_id":42,"dup":false,"project_ref":"WINTASK","title":"Почини конвейер заявок: с 12:10 падает cron выгрузки"}
```

- `task_id` — ID созданной задачи (её видно в дереве);
- `dup:true` — такая же незакрытая задача уже есть, новая не создана;
- `dry_run:true` в ответе — запрос был проверкой, ничего не создано.

## Готовые примеры

Проверить, что запрос разберётся (задача не создаётся):

```bash
# с сервера агента — ключ не нужен
curl -s -X POST http://5.144.179.170:8080/api/task_queue.php \
  -H "Content-Type: application/json" \
  -d '{"project_ref":"WINTASK","title":"Проверка связи","dry_run":true}'
```

Поставить задачу на фикс:

```bash
curl -s -X POST http://5.144.179.170:8080/api/task_queue.php \
  -H "Content-Type: application/json" \
  -d '{
        "project_ref":"ADULT",
        "title":"Восстанови выгрузку заявок в fapacrm: cron падает с 12:10",
        "prio":1,
        "source":"agent-selfcheck",
        "note":"в логе timeout 30s на шаге выгрузки"
      }'
```

Если с чужого адреса — добавь `-H "X-Ingest-Key: $KEY"`.

Python (urllib, без внешних библиотек):

```python
import json, urllib.request

req = urllib.request.Request(
    "http://5.144.179.170:8080/api/task_queue.php",
    data=json.dumps({
        "project_ref": "ADULT",
        "title": "Восстанови выгрузку заявок в fapacrm: cron падает с 12:10",
        "source": "agent-selfcheck",
    }).encode(),
    headers={"Content-Type": "application/json"},   # с сервера агента ключ не нужен
    method="POST")
print(urllib.request.urlopen(req, timeout=30).read().decode())
```

## Ограничения (чтобы не превратить это в спам)

1. **Дубли не создаются.** Если такая же незакрытая задача уже есть в направлении —
   вернётся `dup:true`.
2. **Не больше 3 открытых задач от одного `source`** в одном направлении.
   Дальше — отказ с `429` и объяснением. Если ты стучишься с одним и тем же
   `source`, значит он уже есть в плане: дождись выполнения.
3. **Одна задача — одна строка.** Агент получает только текст `title`.
4. **Сторож отдаёт по одной задаче.** Пока агент занят, новая ждёт.

## Что будет дальше

1. Задача появляется в дереве трекера (как любая задача) с пометкой
   «источник: …» и событием в ленте.
2. Сторож выдаёт её агенту, когда тот свободен — агент видит только текст задачи.
3. Ответ агента с токенами закрывает задачу, токены и стоимость пишутся в учёт.

Проверить свою задачу можно в трекере: `http://5.144.179.170:8080/?page=tree`
(задачи по направлениям) и `http://5.144.179.170:8080/?page=usage` (учёт вызовов).
